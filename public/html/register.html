Пользовательский договор Prana-IT

1. Общие положения

Настоящий договор регулирует использование личного кабинета Prana-IT для подачи заявок, обмена сообщениями, файлами и отслеживания работ по цифровым проектам.

2. Права и обязанности пользователя

Пользователь обязуется указывать достоверные данные, не передавать доступ третьим лицам и использовать сервис только для законного взаимодействия с Prana-IT. Пользователь вправе получать информацию о проектах, направлять материалы и обращаться в поддержку.

3. Обработка персональных данных

Prana-IT обрабатывает имя, контакты, сведения о компании, сообщения, файлы и технические данные для регистрации, поддержки, выполнения заявок и коммуникации по проектам.

4. Платежи

Информация о платежах отображается в личном кабинете в справочных целях. Условия оплаты, сроки, возвраты и закрывающие документы определяются отдельными счетами, договорами или приложениями к ним.

5. Удаление аккаунта

Пользователь может запросить удаление аккаунта в настройках. При удалении удаляются связанные данные личного кабинета, включая проекты, сообщения, уведомления, файлы и историю платежей, если иное не требуется законом или бухгалтерским учетом.

6. Ограничение ответственности

Сервис предоставляется как рабочий инструмент для коммуникации. Prana-IT не отвечает за последствия передачи пользователем некорректных данных, утраты доступа по вине пользователя или действий третьих лиц вне контроля Prana-IT.

7. Контактная информация
